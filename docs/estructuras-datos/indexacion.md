# Indexación

```python
secuencia[2]   # desde la izquierda
secuencia[-3]  # desde la derecha
```

```python
secuencia[1:4]  # slicing
secuencia[:3]   # desde primer elemento
secuencia[2:]   # hasta último elemento
secuencia[:]    # todo
```

```python
secuencia[::2]   # con paso
secuencia[::-1]  # orden inverso
```
