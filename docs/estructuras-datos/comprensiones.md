# Comprensiones

```python
[expresión for elemento in iterable]  # listas
[expresión for elemento in iterable if condición]
```

```python
{expresión for elemento in iterable}  # conjuntos
{expresión for elemento in iterable if condición}
```

```python
{expresión: expresión for elemento in iterable}  # diccionarios
{expresión: expresión for elemento in iterable if condición}
```
