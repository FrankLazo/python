# Métodos de listas

- `.append()` → Agregar al final
- `.insert()` → Agregar por índice
- `.extend()` → Agregar otra lista
- `.remove()` → Eliminar por elemento
- `.clear()`  → Eliminar todos los elementos
- `.pop()`    → Eliminar por índice y devolver elemento
- `.sort()`   → Ordenar lista
- `.copy()`   → Obtener copia
