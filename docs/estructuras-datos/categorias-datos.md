# Categorías de datos

- **Iterable** → Objeto cuyos elementos pueden **recorrerse uno a uno**
- **Secuencia** → Objeto **iterable ordenado** con acceso por **índice**
- **Colección** → Objeto para **almacenar múltiples valores**

| Tipo de dato | Colección | Secuencia | Iterable |
| :---         |   :---:   |   :---:   |  :---:   |
| `list`       | ✔         | ✔         | ✔        |
| `tuple`      | ✔         | ✔         | ✔        |
| `str`        | ❌        | ✔         | ✔        |
| `range`      | ❌        | ✔         | ✔        |
| `dict`       | ✔         | ❌        | ✔        |
| `set`        | ✔         | ❌        | ✔        |
