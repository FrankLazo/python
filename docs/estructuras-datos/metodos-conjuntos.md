# Métodos de conjuntos

- `.add()`     → Agregar un único elemento
- `.update()`  → Agregar elementos
- `.remove()`  → Eliminar elementos (posible error)
- `.discard()` → Eliminar elementos (sin error)
- `.pop()`     → Eliminar y devolver un elemento cualquiera
- `.clear()`   → Eliminar todos los elementos
- `.copy()`    → Obtener copia
