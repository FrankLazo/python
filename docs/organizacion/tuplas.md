# Tuplas

Estructura de datos **ordenada** e **inmutable**: `tuple`

```python
tupla_vacia = ()
numeros = (10, 20, 30, 40, 50)
datos = ("Ana", 20, 1.65, False)
```

```python
t_unitaria = (12,)  # tupla unitaria
```

## Empaquetado y desempaquetado

```python
tupla = 10, 20, 30  # empaquetado de tupla
```

```python
a, b, c = tupla  # desempaquetado de tupla
```

```python
a, b = b, a  # intercambio de variables
```
