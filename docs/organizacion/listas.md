# Listas

Estructura de datos **ordenada** y **mutable**: `list`

```python
lista_vacia = []
numeros = [10, 20, 30, 40, 50]
datos = ["Ana", 20, 1.65, False]
```

## Métodos

- `.append()` → Agregar al final
- `.insert()` → Agregar por índice
- `.extend()` → Agregar otra lista
- `.remove()` → Borrar por elemento
- `.clear()`  → Borrar todos los elementos
- `.pop()`    → Borrar por índice y devolver elemento
- `.sort()`   → Ordenar lista
- `.copy()`   → Obtener copia
