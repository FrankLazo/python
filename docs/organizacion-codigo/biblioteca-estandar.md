# Biblioteca estándar

- `math`     → Matemáticas
- `random`   → Números y elecciones aleatorias
- `datetime` → Fechas y horas
- `pathlib`  → Rutas de archivos y carpetas
- `shutil`   → Operaciones con archivos y carpetas
- `json`     → Trabajar con JSON
- `os`       → Interacción básica con el sistema operativo
- `sys`      → Interacción con Python
- `re`       → Expresiones regulares
- `time`     → Tiempo
