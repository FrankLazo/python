# Devolver valores

```python
def sumar(a, b):
    return a + b
```

```python
def mostrar_mensaje():
    print("Hola")
```

```python
def operaciones(a, b):
    suma = a + b
    resta = a - b
    return suma, resta
```

```python
resultado = sumar(20, 30)        # 50
resultado = mostrar_mensaje()    # None
resultado = operaciones(70, 50)  # (120, 20)
```
