# Expresiones

| Tipo de expresión | Resultado | Expresiones de muestra    |
| :---              | :---      | :---                      |
| Aritméticas       | Número    | `((a + b) * 5) / 100`     |
| De comparación    | Booleano  | `edad >= 18`              |
| Lógicas           | Booleano  | `a > b and b > c`         |
| De concatenación  | Cadena    | `nombre + " " + apellido` |
