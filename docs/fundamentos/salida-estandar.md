# Salida estándar

Salida de datos normalmente conectada a la **pantalla**

```python
print()                   # línea vacía
print("Python")           # final con salto de línea
print("Python", end=" ")  # final con espacio
```

```python
print("A", "B", "C")           # A B C
print("A", "B", "C", sep="-")  # A-B-C
```
