# Asignación

- Asignación simple: `=`
- Asignación con suma (**incremento**): `+=`
- Asignación con resta (**decremento**): `-=`
- Asignación con multiplicación: `*=`
- Asignación con división decimal: `/=`
- Asignación con división entera: `//=`
- Asignación con residuo: `%=`
- Asignación con potencia: `**=`
