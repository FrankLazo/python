# Tipos de datos

| Tipo    | Descripción           | Valores de muestra    |
| :---    | :---                  | :---                  |
| `int`   | Números enteros       | `-37` `0` `37`        |
| `float` | Números flotantes     | `-37.0` `0.0` `37.0`  |
| `str`   | Cadenas de caracteres | `"String"` `'String'` |
| `bool`  | Booleanos             | `True` `False`        |

Mostrar tipos de datos:

```python
print(type(37))       # <class 'int'>
print(type(37.0))     # <class 'float'>
print(type("Texto"))  # <class 'str'>
print(type(False))    # <class 'bool'>
```
